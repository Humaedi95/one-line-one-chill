A single horror sentence, under 200 characters, meant to frighten in one breath.

> My daughter whispered, 'Daddy, the man in my closet sounds just like you' — and I was home alone.

**Character count: 97** (under the 200-character limit).

## How it runs

```sh
node main.ts
```

`main.ts` validates the line (a single line, a single sentence, 1–200 characters, not only whitespace) and writes it, plus a trailing newline, to `/output/entry.txt`.
